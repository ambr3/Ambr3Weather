Ambr3Weather v0.3.19 Changes
=============================

UI Improvements
- Header attribution visible on mobile (flex-wrap, smaller font)
- Day summary pill in first card: high/low, rain %, wind
- Daily forecast shows mm or cm only (removed hours display)
- Hourly forecast shows % probability only (removed snow/precip fallbacks)
- Historic weather: high/low colors (#ff6b6b/#74b9ff) with glow, "10 years of data" note
- Pollen graph: fixed scaling (v/100 instead of v/maxVal), level-based bar colors
- Map simplified: removed temp badges, removed wind badge, zoom 12 (~5mi)
- Map badge: weather icon + temp + wind direction arrow (replaced temp pill)

Security & Robustness Audit
- Removed dead getLocalTemps() function from api.js
- Removed unused variables (precipHours, precip, snow) from ui.js
- Fixed timezone bug: forecast/historic date labels now use city timezone
- Fixed null-safety: wind direction arrow hidden when data missing
- All innerHTML interpolations verified safe (escaped or numeric)
- All localStorage access wrapped in try/catch
- All async flows guarded against race conditions
- All promises have catch handlers
- CSP properly locked down, no secrets, referrer policy set
